HEARTH: START HERE

Use Start Agents.cmd on Windows, or macos/Start Agents.command on a Mac.
Choose Codex, Claude Code, or both. Node.js 18 or newer and Git are required.
The picker shows the paths before it asks for permission to write.

A blank project folder installs user skills only. Choosing a project also wires
project-local instructions and hooks. Existing skills require explicit
replacement consent and are retained in .eidolon/backups with a receipt.

In Codex, restart in the target project, review project trust, then inspect and
trust /hooks. A skill file alone does not provide executable enforcement.
Use $eidolon and $setup in Codex, or /eidolon and /setup in Claude Code.

Codex ask-tier operations stay blocked for manual operator review; the adapter
never silently treats an unsupported approval response as permission.

The original graphical installers remain Claude-only. Their text fallback opens
the new picker. Their optional external services are separate from the bundled
skills. Review current official instructions before installing optional tools.

README.md explains compatibility limits. gui/TESTING.md lists live-client and
GUI checks still needed before release. CREDITS.md and LICENSE preserve credit
and licensing, including the ASI-Evolve engine's separate Apache-2.0 terms.
