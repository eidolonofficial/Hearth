HEARTH: READ ME FIRST

What this is
Hearth puts two skills into Claude Code: Setup and Eidolon. That is all it does.

What will happen
1. You double-click "Start Here.cmd".
2. A window opens and says what it will do.
3. It copies the two skills into the .claude\skills folder in your user folder.
4. It lists each file as it copies it, then tells you what is installed.

Nothing runs without your yes
If you already have a skill with the same name, Hearth asks you first. You type
"replace" to swap it, or press Enter to skip. Skip is the default. If you replace,
your old copy is saved first, in .claude\skills\.hearth-backups, under the date and time.

Nothing else is installed. No extra programs, no background tasks, no account sign-in.

How to start
Open Claude Code. Type /setup or /eidolon.

If something goes wrong
Hearth tells you the one thing to try. Nothing is broken when it stops. You can run
"Start Here.cmd" again.

How to undo
Delete these two folders from the .claude\skills folder in your user folder:
  eidolon
  setup
If Hearth saved an older copy, it is in .claude\skills\.hearth-backups. Move it back.

For people who want project hooks
There is a second door, "Operator Setup.cmd". It needs Node 22 or newer. You do not
need it for the steps above.
