HEARTH ON macOS

Open Start Agents.command in this folder to choose Codex, Claude Code, or both.
This picker uses Terminal. Node.js 18 or newer on PATH and Git are required.
It previews its changes and asks for explicit approval; replacement is separate
and retains a backup. Nothing installs optional services through this picker.

Hearth.app remains the legacy Claude-only graphical interface. Its Back or
Cancel choice does not authorize a copy. Its text fallback opens Start Agents.
Unsigned application launch and native GUI behavior still require testing on
your macOS version; do not assume a Linux or Node test proves the GUI works.

After a Codex project install, restart Codex and review project trust and /hooks.
See the parent folder's README.md for installation scope and limitations.
