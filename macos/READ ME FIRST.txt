HEARTH ON macOS: READ ME FIRST

Status: run on GitHub's macOS test machines on 2026-10-13 (it copied, skipped and
replaced there) and on Linux. It has not been run on a person's own Mac yet.

What this is
Hearth puts two skills into Claude Code: Setup and Eidolon. That is all it does.

What will happen
1. You open "Welcome.command" in this folder. Terminal opens.
   If macOS blocks it, right-click the file, choose Open, then confirm.
2. It says what it will do.
3. It copies the two skills into the .claude/skills folder in your home folder.
4. It lists each file as it copies it, then tells you what is installed.

Nothing runs without your yes
If you already have a skill with the same name, Hearth asks you first. You type
"replace" to swap it, or press Enter to skip. Skip is the default. If you replace,
your old copy is saved first, in .claude/skills/.hearth-backups, under the date and time.

Nothing else is installed. No extra programs, no background tasks, no account sign-in.

How to start
Open Claude Code. Type /setup or /eidolon.

If something goes wrong
Hearth tells you the one thing to try. Nothing is broken when it stops. You can open
"Welcome.command" again.

How to undo
Delete these two folders from the .claude/skills folder in your home folder:
  eidolon
  setup
If Hearth saved an older copy, it is in .claude/skills/.hearth-backups. Move it back.
(In Finder, press Command-Shift-Period to show folders that start with a dot.)

For people who want project hooks
There is a second door, "Operator Setup.command". It needs Node 22 or newer. You do
not need it for the steps above.
